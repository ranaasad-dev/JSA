DAILY USE
Properties & gallery > Add property > Details > Pictures > Publish changes.
Reference JEA-001, JEA-002... automatically suggest hota hai; duplicate allowed nahi.
English aur Urdu dono fields fill karein. Empty Urdu par English fallback hota hai.
Price sirf owner ki confirmation par likhein. Khaali price public card par nahi dikhayi jayegi.
Cover button se first image select karein. Delete property se photo storage se delete nahi hoti.
Image library mein unused photos alag delete kar sakte hain.
JPG/PNG/WebP upload: original maximum 20 MB; browser long side 2000px tak resize karta hai.
Stored image maximum 5 MB. SVG/HTML uploads allowed nahi.
Mobile photos aur poster ka original apne computer par rakhein.
Publish se public content save hota hai. Visitors page load/refresh par latest content dekhte hain.
Ek hi waqt multiple admin tabs mein edits na karein; conflict par backup lein, phir reload karein.

LIMITS / IMPORTANT DETAILS
- Main Admin ka login, authenticated uploads aur live save aapko apne account se test karne hain.
  Password ki zaroorat assistant ko nahi hai. Simulated UI test live permissions test nahi hota.
- WhatsApp/call messages automatically read/import nahi hote. Private enquiry notes manually hain.
- Public content table mein sirf public website content. Customer phone/notes private table mein.
- Image bucket public hai; usmein private documents na upload karein.
- Site load par Supabase unavailable ho to bundled assets/js/site-content.js use hota hai.
  Dashboard > Backup > Export site-content.js ko GitHub mein update karte rahein, warna offline
  fallback purana content/empty gallery dikha sakta hai.
- Default theme/language new visitors ke liye; old visitors ki saved preference respect hoti hai.
- Social previews/crawlers JS metadata par rely nahi karte. Basic SEO edit ke baad Backup tab se
  jsa-seo.json export karein. File project folder mein rakh kar:
    python apply-seo.py jsa-seo.json .
  Phir changed index.html, gallery.html, contact.html GitHub par upload karein.
- No payments, checkout, booking or online transaction system.
- Existing Firebase counters are separate. Yeh dashboard unko reset nahi karta.
- Free service usage limits apply; no paid service added by this package.
- Backup JSON public content ka hai; images, inquiry export aur Firebase data alag backups hain.

ROLLBACK
GitHub mein upgrade commit revert kar sakte hain, ya saved original files restore kar sakte hain.
Supabase tables/images ko rollback ke liye delete karna zaroori nahi.
